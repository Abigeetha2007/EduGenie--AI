# EduGenie-AI

## Google Gemini Powered Learning Assistant

EduGenie-AI is an AI-powered learning assistant designed to help students understand topics, clarify doubts, and improve their learning experience. It uses Google Gemini API to generate responses to students' questions through a simple and user-friendly web interface.

## Project Overview

EduGenie-AI provides an interactive platform where students can ask questions and receive AI-generated explanations. The application is developed using HTML, CSS, FastAPI, Jinja2, and Google Gemini API.

## Technologies Used

* **HTML** – Creates the structure of the web application.
* **CSS** – Designs and styles the user interface.
* **FastAPI** – Handles backend operations and API requests.
* **Jinja2** – Renders dynamic HTML templates.
* **Google Gemini** – Generates AI-powered responses.
* **Google Gemini API** – Connects the application with the Gemini AI model.
* **Python** – Used for backend development.

## How to Run the Project

1. Clone or download this repository.

2. Open the project folder in Visual Studio Code.

3. Create and activate a Python virtual environment.

4. Install the required dependencies using:

   `pip install -r requirements.txt`

5. Configure your Google Gemini API key.

6. Run the FastAPI application.

7. Open the local application URL in your browser.
